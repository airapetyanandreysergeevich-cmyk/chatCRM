- Свой формат номера заказа: в «Настройках → Базы» можно задать первый номер — SC01, З-001, 1000 — и, по желанию, год в номере (SC-2026-01, тогда счёт каждый январь начинается заново). Задаётся, пока в мастерской нет ни одного заказа.
- Правый щелчок по телефону, имени клиента, номеру заказа или серийному номеру — «Копировать». Работает везде, где они показаны, и в мастерской по локальной сети тоже.
- В полях ввода программы по правому щелчку теперь есть «Копировать» и «Вставить».
