- SMS со своего телефона: приложение «FineCRM SMS» для Android отправляет SMS клиентам с SIM-карты мастерской — без SemySMS и других сервисов. Подключение по QR-коду в «Настройки → Интеграции».
- Настройки стали аккуратнее: панели сворачиваются и раскрываются по нажатию, при входе свёрнуты, а раскрытые запоминаются. Выключили SMS — панель сворачивается в строку.
