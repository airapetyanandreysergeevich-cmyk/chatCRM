- Своё имя мастерской вместо приставки local: в «Доступе из интернета» владелец выбирает короткое имя, например lenina, и логины сотрудников становятся вида nikita@lenina — одинаковыми в мастерской и на www.finecrm.ru. Переименование — по таблице с подтверждением, пароли не меняются. Прежние приставки вида .local4 больше не работают: пока имя не выбрано, войти из интернета нельзя.
- В локальной сети можно входить просто по имени, без окончания: nikita вместо nikita@lenina.
- Кто по привычке вводит прежний логин с верным паролем, видит подсказку с новым.
- Клиенты и заказы: сортировка (по имени, по цвету метки, по сумме оплат, сначала горящие и другие) и отбор по цветной метке. Склад: сортировка, в том числе «сначала заканчивающиеся».
- У каждого клиента своя карточка: все его заказы, сколько раз приходил, сколько заплатил и средний чек. Из заказа в неё ведёт имя клиента.
