- Фильтры заказов запоминаются: вышли из списка или закрыли программу — при возвращении фильтры те же. У каждого сотрудника свои.
- В фильтрах можно выбрать несколько стадий сразу, например «Согласование» и «Ремонт». Без фильтра выделено всё: лишнее снимается нажатием, «Все» выделяет всё или снимает всё. Так же с типами техники.
- Согласование по SMS: клиент получает вопрос с ценой и отвечает «да» или «нет», ответ приходит в заказ. При согласии заказ сам переходит в работу, при отказе остаётся с пометкой, непонятный ответ решаете кнопкой. Включается в «Настройки → Интеграции». Нужно приложение FineCRM SMS 1.2.
- «Согласовать по SMS» в меню заказа по правой кнопке; при переводе заказа на согласование программа предлагает спросить клиента.
- Приём по гарантии: у выданного заказа — «Принять по гарантии» в меню и в карточке. Новый заказ получает свой номер, а квитанция называется «Акт приема оборудования в ремонт по гарантии».
- Поиск запчастей: у Aitech «в наличии» теперь только то, что действительно есть, и видно сколько штук.
- SemySMS убран: SMS уходят только со своего телефона.
