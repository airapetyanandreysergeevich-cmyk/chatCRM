- Сотрудникам больше не нужно переписывать адрес Основы: при установке программы в режиме «Клиент» она сама найдёт Основу в сети мастерской и покажет её название — остаётся нажать «Подключиться».
- Основа теперь всегда доступна компьютерам мастерской: включать раздачу в меню больше не нужно. В общедоступных сетях (кафе, гостиница) Windows по-прежнему её не показывает.
- Если роутер выдал Основе новый адрес, программы сотрудников находят её сами — без переустановки и звонков владельцу.
- Программа сотрудника запоминает, к какой Основе подключена, и больше не спрашивает об этом при каждом запуске.
- Если в мастерской несколько роутеров, Основу можно найти в другом диапазоне адресов — достаточно вписать первые три числа, например 192.168.0.
- Адрес Основы можно вводить просто цифрами — «http://» и порт программа допишет сама.
- Сменить подключение можно в любой момент без переустановки: меню значка возле часов → «Сменить подключение…».
