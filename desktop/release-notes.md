- «Редактор панелей заказа» в «Настройки → Интерфейс»: какой будет карточка заказа на главном экране. Можно показать неисправность, клиента, сумму, статус, метку клиента, задать размер шрифта, жирность, выравнивание, число строк и ширину каждого элемента, переставить элементы мышью, поменять поля карточки и расстояние между строками. Предпросмотр — на настоящих заказах.
- Карточка у каждого сотрудника своя. Владелец может нажать «Сделать так у всех» — тогда у всех будет одинаковая.
