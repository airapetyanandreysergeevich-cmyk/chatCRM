# Фирменные знаки платформ

Сюда кладутся официальные знаки Android, Apple и Windows для плиток на
странице входа. Пока файлов нет, плитки показывают силуэты устройств из
нашего набора — страница при этом выглядит целой, просто скромнее.

Имена строго такие, иначе не подхватится — и строчными буквами: сервер
различает регистр, а Windows, где файлы обычно готовят, нет.

    android.png
    ios.png
    windows.png

Подойдёт и SVG — тогда поменяйте расширение в `src/components/AppLinks.tsx`,
одна строка на платформу.

Брать только у владельцев марки, не со стоковых сайтов: там условия
использования не прилагаются, а у знаков они есть.

- Android — Google Brand Resource Center, раздел Android
- Apple — Apple Marketing Resources and Identity Guidelines
- Windows — Microsoft Trademark and Brand Guidelines

**Нужен светлый (белый или монохромный) вариант.** Страница входа тёмная, и
тёмно-серый знак на ней просто исчезнет. У всех трёх владельцев такие версии
есть готовыми — брать лучше их, а не перекрашивать файл самому: правила
владельцев марок это иногда прямо запрещают.

Фон у файла должен быть **прозрачным**: подложка своя, и белый прямоугольник
внутри белого поля выглядел бы заплаткой.

Размер значка — 18×18, вписывается по содержимому, поэтому квадратный SVG с
небольшими полями подойдёт лучше всего.
