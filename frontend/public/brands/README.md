# Фирменные знаки платформ

Сюда кладутся официальные знаки Android, Apple и Windows для плиток на
странице входа. Пока файлов нет, плитки показывают силуэты устройств из
нашего набора — страница при этом выглядит целой, просто скромнее.

Имена строго такие, иначе не подхватится:

    android.svg
    ios.svg
    windows.svg

Брать только у владельцев марки, не со стоковых сайтов: там условия
использования не прилагаются, а у знаков они есть.

- Android — Google Brand Resource Center, раздел Android
- Apple — Apple Marketing Resources and Identity Guidelines
- Windows — Microsoft Trademark and Brand Guidelines

**Берите светлый (белый или монохромный) вариант.** Страница входа тёмная, и
тёмно-серый знак на ней просто исчезнет. По той же причине не перекрашивайте
файлы сами: у всех трёх владельцев есть готовые варианты для тёмного фона, а
самовольная перекраска обычно прямо запрещена их же правилами.

Размер значка — 18×18, вписывается по содержимому, поэтому квадратный SVG с
небольшими полями подойдёт лучше всего.
